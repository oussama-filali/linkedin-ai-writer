  TOTAL: ~1000ms + risque d'erreurs

  TOTAL: ~500ms (2x plus rapide !)

🐛 DEBUGGING

  Si ça ne marche pas:

  1. Vérifie la configuration Supabase
     → Authentication → Configuration
     → Site URL: linkedinaiwritermobile://
     → Email Confirmations: OFF (pour dev)

  2. Vérifie app.json
     → extra.supabase.url
     → extra.supabase.anonKey

  3. Regarde les logs
     → Terminal: npm start
     → Logs détaillés en cas d'erreur

  4. Test manuel Supabase
     → Dashboard → Authentication → Users
     → Crée un utilisateur de test
